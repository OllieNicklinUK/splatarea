Viverse AI Agent — Implemented Agent Harness Methods

Source: src/services/OrchestratorService.js & src/services/WorkflowStageService.js  |  Generated 2026-05-05

1. Agent Roles (Harness Participants)

Role Task IDs Stage Purpose
Architect architect, task_architect plan Designs the app contract; generates the execution plan
Coder / Auth Preflight auth_preflight auth_preflight Bootstraps / verifies VIVERSE SDK auth before coding begins
Coder / Scaffold scaffold tasks scaffold_preflight Runs create-vite / template scaffolding
Coder / Logic coder_logic, task_template_logic implement Implements gameplay / app logic
Coder / Publish coder_publish, task_template_publish publish Runs viverse-cli app publish to deploy the app
Reviewer task_reviewer verify Reviews coder output for runtime correctness & SDK compliance
Verifier task_verifier verify Deterministic release checks: App ID gate, SDK URLs, auth gate, publish-readiness

2. Key Harness Orchestration Methods (OrchestratorService)

Method Purpose
processRequest() entry point Main async generator — iterates tasks, dispatches by role, handles streaming & retries
_classifyRequestIntent() Routes to new_app / logic_iteration / asset_iteration harness based on message analysis
_enforceWorkflowTasks() Injects and wires all required tasks (auth_preflight → coder → reviewer → verifier); patches missing deps
_splitCombinedCoderTasks() Splits monolithic coder tasks into logic + publish subtasks
_canonicalizeTemplateWorkflowTasks() Normalizes template-bound task definitions against registry
_pruneLegacyTasksAfterSplit() Removes superseded task entries after task splitting
_runAuthAcceptanceGate() async Validates VIVERSE SDK auth bootstrap is in place before execution proceeds
_runTemplateCompletionGates() async Runs template certification gates post-publish
_ensureArchitectContract() async Materializes and persists the Architect's contract artifact to workspace
_ensureRuntimeRevalidationTask() Injects a re-verification task after a fix cycle completes
_scheduleAutoTestFixTask() Schedules a coder fix task when browser runtime probe fails
_scheduleDeterministicVerifierFixTask() Schedules a targeted fix task based on verifier failure signature
_reviveTransientInfraFailedTasks() Re-queues tasks that failed due to transient infrastructure errors on resume
_reviveStaleBlockedTasks() Unblocks tasks stuck in a blocked state on resume
_reclassifyObsoleteSkillComplianceFailures() Tolerates stale skill compliance failures when skill ledger has since been satisfied
_finalizeWorkflowState() async Persists final workflow outcome (completed / paused / failed) to state store

3. WorkflowStageService Methods

Method Purpose
stageForTask(task) Derives the pipeline stage name (plan, auth_preflight, scaffold_preflight, publish, verify, implement) from task role / id / prompt
transition(state, stage, meta) Transitions workflow to a new stage; appends entry to stageHistory
transitionForTask(state, task, meta) Derives stage from task and calls transition()
markFinalize(state, meta) Transitions workflow to the finalize terminal stage

4. Harness Flow — 3 Routing Modes

new_app — Full pipeline
Architect → auth_preflight (Coder) → Coder/scaffold → Coder/logic → Coder/publish → Reviewer → Verifier
logic_iteration — Skip Architect & app creation
auth_preflight (Coder) → Coder/logic → Coder/publish → Reviewer → Verifier
asset_iteration — Visual-only edits, no auth, no Reviewer
Coder/asset → Coder/publish → Verifier
